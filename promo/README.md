# AI 윤리 판정소 홍보영상

- `edu-ethics-promo.mp4`: 1920×1080, 30fps, 약 60초. 배경음악과 하단 한국어 자막이 들어 있습니다.
- 실제 앱 화면을 녹화해 편집했습니다. 들어간 장면은 3차시 수업 소개, 수업코드 입장(교사 화면 + 학생 휴대폰), 신호등 판정과 이유 선택, 결과 공개와 재판정 변화, 윤리 열쇠, 2차시 딜레마 배틀, 3차시 AI 윤리 재판소, 우리 반 AI 사용 규칙입니다.
- 화면에 나오는 학생 이름('하늘')과 투표 28명은 녹화용 가상 데이터입니다. 실제 학생 정보는 쓰지 않았습니다.
- `edu-ethics-promo.srt`: 자막 파일입니다. 유튜브 등에 자막을 따로 올릴 때 씁니다.
- `source/`: 영상을 다시 만들 때 쓰는 녹화·편집 스크립트입니다. 앱 배포에는 포함되지 않습니다.

## 다시 만들기 (개발자용)

1. 저장소 루트에서 `npm run dev`를 실행합니다. `.env.local` 없이 실행하면 Supabase를 쓰지 않는 "같은 기기 데모" 모드로 열립니다.
2. 작업 폴더에서 `node source/go.mjs home|l1|l2|l3`로 화면을 녹화합니다. 결과는 `clips/`에 저장됩니다. 녹화 중에는 배포 주소(edu-ethics.vercel.app) 요청을 로컬 서버로 돌려 받으므로, 실제 배포 서버에는 접속하지 않습니다.
3. `clips/<이름>.mp4`를 `frames/<이름>/%05d.jpg`로 풀고 `compose.html`, `music.wav`(`python3 source/music.py`로 생성)와 같은 폴더에 둡니다.
4. `node source/render.mjs`로 `out/` 프레임을 렌더한 뒤 ffmpeg로 `music.wav`와 합칩니다.

폰트는 Pretendard(시스템에 설치)를 씁니다. 배경음악은 numpy로 직접 합성했기 때문에 저작권 문제가 없습니다.
